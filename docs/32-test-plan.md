# План тестирования: поверхность Goosar 1.1

Актуальность: 25 сентября 2026 года.

## 1. Матрица окружений

Экран × тема × клиент × локаль:

```text
{список задач, карточка задачи, лендинг}
  × {светлая, тёмная}
  × {web Chrome 130+, web Safari 18+, desktop macOS arm64, desktop Windows x64}
  × {ru, en}
```

Обязательны все сочетания для web Chrome; для Safari и desktop достаточно светлой темы и ru; zh-Hans и ja проверяются только на отсутствие `MISSING`-ключей.

## 2. Обязательные проверки

- клавиатурный проход по рельсе и панели: Tab, Enter, `[` для сворачивания, `⌘K` для поиска, `C` для новой задачи;
- панель свёрнута → перезагрузка → панель свёрнута;
- список 500 задач: прокрутка без long tasks дольше 50 мс;
- переключение список ↔ доска сохраняет фильтры;
- карточка на ширине 1024px и 1440px;
- смена локали без перезагрузки не оставляет непереведённых ключей;
- тёмная тема: ни одного элемента с текстом ниже 4.5:1 (проверка axe DevTools);
- лендинг без сетевых запросов из ленты и с Lighthouse Performance ≥ 90;
- десктоп macOS: кнопки окна не перекрывают рельсу; Windows: заголовок окна стандартный;
- `pnpm typecheck`, `pnpm --filter @goosar/views test`, `pnpm --filter @goosar/ui test`, `go test ./...` зелёные.

## 3. Проверки безопасности

- лента лендинга читает только `demo-log.ts` (Network пуст);
- новые компоненты не используют `dangerouslySetInnerHTML`;
- заголовки задач с HTML и эмодзи в строке списка экранируются (ввести `<img src=x onerror=alert(1)>` как заголовок).

## 4. Нагрузка

Рендер списка 2000 задач в jsdom не дольше 1.5 с (тест в `issue-list.test.tsx` с `performance.now()`); в браузере — прокрутка 500 задач по пункту из раздела 2. Бэкенд не нагружаем: он не менялся.

## 5. Смоук после деплоя 1.1.0

1. `curl -sf https://goosar.ru/health` → `{"status":"ok"}`.
2. Открыть goosar.ru: первый экран с терминальной лентой, без старого скриншота.
3. Войти, открыть `/{ws}/issues`: рельса слева, список по умолчанию.
4. Создать задачу клавишей `C`, открыть, передать агенту, закрыть.
5. Переключить тему: рельса остаётся тёмной, контраст читаемый.
6. Переключить локаль на en: термины task, feed, crew.
7. Свернуть панель `[`, перезагрузить: свёрнута.
8. Десктоп: запустить сборку, окно без белой полосы заголовка.

## 6. Что не тестируем

- мобильное приложение: не в объёме 1.1;
- локали zh-Hans и ja визуально: нет носителя, проверяется только полнота ключей;
- Firefox: в матрицу не входит до появления пользователей на нём;
- совместимость с форками, изменившими ключи локалей: ключи не менялись, риска нет.

## 7. Эвристический аудит (28.09.2026)

T-023. Три экрана (`/gusar/issues`, карточка задачи, `/`) проверены по 10 эвристикам NN/g на живом стенде (Playwright-скриншоты light/dark, чтение DOM) против эталона ADR-0006. Найдено 15 наблюдений, 7 закрыты правкой кода — три из них (смена статуса без отмены) относятся к одному общему компоненту `StatusPicker`, поэтому одна правка закрывает сразу три строки таблицы (список, доска, карточка).

| Экран | Эвристика № | Находка | Статус |
|---|---|---|---|
| Список задач | 3 (контроль и свобода) | Смена статуса пикером в строке списка необратима одним кликом | исправлено |
| Доска (канбан) | 3 (контроль и свобода) | Смена статуса пикером на карточке доски необратима | исправлено |

| Карточка задачи | 3 (контроль и свобода) | Быстрая кнопка «Готово» сразу закрывает задачу без возможности отмены | исправлено |
| Карточка задачи | 1 (видимость статуса системы) | Автосохранение заголовка (`onBlur`) не показывало, что изменение сохраняется | исправлено |
| Карточка задачи | 1 (видимость статуса системы) | Автосохранение описания (debounce 1500 мс) не показывало, что изменение сохраняется | исправлено |

| Список задач | 6 (узнавание, а не припоминание) | Статус-иконки групп (два вложенных кружка) расшифровываются только в тексте заголовка группы, без иконки-подсказки при свёрнутой группе | отложено |
