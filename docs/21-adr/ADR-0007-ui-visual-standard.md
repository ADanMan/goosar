# ADR-0007: Визуальный эталон, по которому проверяется и правится интерфейс

Дата: 28 сентября 2026 года
Статус: Accepted

## Контекст

ADR-0006 задал эталон поведения (эвристики NN/g, паттерны Carbon, HIG), и по нему прошло комплексное ревью T-031. Визуальный слой — цвета, контраст, шрифты, отступы, радиусы, единообразие компонентов между экранами и тёмная тема — по эталону не проверялся. Палитра «Речная синь» и шрифты введены в 1.1.0 без формальных порогов, поэтому расхождения между экранами и сайтом накапливаются незаметно.

## Рассмотренные варианты

- Оценка «на глаз» — быстро / невоспроизводимо, спор не решить;
- Проверяемые числовые правила: WCAG 2.2 AA для контраста, 4/8-пиксельная сетка, одна типографическая шкала, цвета только через токены, правила токенов Carbon — каждое правило считается скриптом или grep / нужен один документ и пара скриптов;
- Полная дизайн-система со Storybook — целостно / объём в разы больше пользы для соло-продукта.

## Решение

Интерфейс проверяется по пяти числовым правилам:

1. Контраст: текст ≥ 4.5:1, крупный текст и UI-компоненты ≥ 3:1 (WCAG 2.2 AA), считается по токенам в обеих темах скриптом;
2. Сетка: отступы и размеры кратны 4px, вертикальный ритм кратен 8px;
3. Типографика: одна шкала не больше семи размеров; заголовки Unbounded, текст Manrope, код JetBrains Mono; line-height основного текста 1.4–1.6; произвольные `text-[…px]` запрещены;
4. Токены: цвета, радиусы, тени только через `var(--…)` из `packages/ui/styles/tokens.css`; статусы через `--status-*`; литералы hex/rgb/oklch в компонентах запрещены;
5. Единообразие: один и тот же элемент выглядит одинаково на всех экранах и на сайте; иконки одного набора и размера в одном контексте; тёмная тема имеет пару для каждого токена.

Проверка выполняется скриптами `scripts/check-ui-strings.mjs` (уже есть) и `scripts/check-ui-tokens.mjs` (появится в T-035: литералы цветов, произвольные размеры, контраст токенов).

## Последствия

Положительные: у каждой визуальной правки есть число, которое она улучшает; ревью повторяемо.
Отрицательные: часть текущих решений (тёмный hero лендинга без светлого варианта, произвольные размеры в старых компонентах) придётся либо узаконить исключением, либо переделать.
Что станет сигналом пересмотреть решение: если после T-035 владелец назовёт визуальные неудобства, которые правилами не ловятся, добавить правило, а не смягчать пороги.
