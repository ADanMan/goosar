## [Unreleased]

### Added
- UI-ревью визуального слоя по ADR-0007: 61 находка в `docs/34-ui-review.md` (T-034); референс ADR-0008 (Atlassian Design System, Fluent 2); перестройка визуала — T-035.
- Комплексное UX-ревью всех экранов по ADR-0006: 75 находок в `docs/33-ux-review.md` (T-031); фиксы Critical/High вынесены в T-032.

### Fixed
- Деинсталлятор десктопа просит подтверждение: при удалении пользовательских данных нужно ввести кодовое слово, раздел переведён на пять языков (T-032).
- Вкладки десктопа: средний клик закрывает вкладку, ⌘W/Ctrl+W не закрывает закреплённую, контекстное меню и страницы ошибок маршрута переведены (T-032).
- Тестовая страница «Оплата» доступна только с `NEXT_PUBLIC_ENABLE_BILLING_TEST_PAGE=true`, показывает понятный текст вместо сырой ошибки API, встроена в подпанель «Настройки» (T-032).
- Вкладка «Деплой» по прямой ссылке показывает загрузку или «Нет прав администратора деплоя» вместо тихого перехода на «Профиль» (T-032).
- Причины падения задач агента и подписи графиков расхода переведены; у «Архивировать» агента иконка архива вместо корзины; у списка сред выполнения появилась строка заголовков (T-032).
- Доступность: aria-label у кнопок окна чата, кнопка архивирования в ленте достижима с клавиатуры; хлебная крошка на «Отрядах» показывает «Отряды» (T-032).
- Сайт: ссылки футера на секции лендинга работают со всех страниц, логотип футера ведёт на главную; на /download показан размер файлов и ссылка на `SHA256SUMS.txt`, релизный workflow публикует контрольные суммы Linux и Windows (T-032).
- Понятные сообщения вместо сырого ответа API: создание задачи, отклонение расписания автопилота, вступление в воркспейс, пакетный приём приглашений (T-033).
- Массовое удаление автопилотов сообщает «удалено N из M» и какие не удалились; пакетный приём приглашений показывает, куда уже присоединились; журнал запусков грузится порциями с «Показать ещё» (T-033).
- Подтверждения и отмена: отклонение приглашения — через диалог, очистка лога демона в десктопе — с «Отменить»; смена адреса и модели LLM-шлюза больше не требует диалога, он остался только для очистки ключа (T-033).
- Пустые состояния: одно вместо двух в «Ленте», один CTA у агентов и отрядов, действие на «Расходе», паттерн empty-state у «Что вы можете здесь делать» и MCP-дефолтов (T-033).
- Доступность: переведённый aria-label индикатора агента, поле комментария объявляется как текстовое, статус сред выполнения виден не только цветом, отдельная иконка для удаляемой среды, краткие имена карточек мастера агента, aria-pressed у переключателя языка, текст hero-терминала для скринридера, причина недоступного формата на /download (T-033).
- Настройки: вкладка «Создание задач», проверка email при приглашении, заголовки колонок у участников, группы вкладок видны на узком экране, предупреждение о незаданном ключе шлюза, «Настраивается: администратор деплоя» только для тех, у кого нет прав; «Что вы можете здесь делать» — в подпанели «Настройки» (T-033).
- Сайт и вход: «Скачать» и «О проекте» в шапке, логотип на экране входа, пункт футера «API» убран, текст листа ожидания на /download без несуществующей кнопки «Пропустить», счётчик символов, спиннер на /invite; чат-виджет скрыт на мастере создания агента (T-033).

## [1.2.0] — 2026-09-28

### Added
- Чат отдельным пунктом рельсы (T-019).
- Новая вкладка в десктопе отовсюду: средняя кнопка и ⌘-клик, «+» с текущим маршрутом, ⌘T, пункт «Открыть в новой вкладке» в меню задачи (T-021).
- Undo-тосты при смене статуса и завершении задачи, индикатор сохранения в карточке, пустое состояние списка с действием (T-023).

### Changed
- Контекстная панель сворачивается видимой кнопкой, клавишей `[` и триггером десктопа; состояние общее и хранится (T-020).
- Разделы «Деплой» и «Админ» по паттернам Carbon: таблицы с поиском и сортировкой, overflow-меню действий, диалоги подтверждения, inline-уведомления, пустые состояния, валидация полей (T-022).

### Fixed
- Смена статуса задачи (список, доска, карточка) и быстрая кнопка «Готово» теперь показывают тост с «Отменить» (T-023, эвристика 3 — контроль и свобода).
- Автосохранение заголовка и описания задачи показывает индикатор «Сохранение…» вместо тихого сохранения без обратной связи (T-023, эвристика 1).
- Кнопка «Передать агенту» в карточке задачи была захардкожена по-русски — теперь переведена на все 5 локалей (T-023, эвристика 4).
- Пустой список задач получил кнопку «Создать первую задачу» вместо текста без действия (T-023, эвристика 8 / паттерн Carbon empty-state).

### Отложено (эвристический аудит T-023, см. `docs/32-test-plan.md` §7)
- Массовое изменение статуса (`BatchActionToolbar`) не предлагает отмену в отличие от одиночной смены статуса.
- Ошибки обновления поля в `batch-action-toolbar.tsx` показывают сырой текст ошибки API вместо унифицированного понятного сообщения.
- `PriorityPicker` не получил отмену по аналогии со `StatusPicker`.
- Массовое удаление задач необратимо без undo-тоста (есть только confirm-диалог).
- Кнопка скачивания на `/download` зависит от JS-детекта ОС без плейсхолдера на время гидратации.
- Рельса навигации в десктопном приложении не сворачивается — известный долг из ADR-0006, вне рамок T-023.
- Иконки статуса групп в списке задач расшифровываются только текстом заголовка, без иконки-подсказки в свёрнутом состоянии.

## [1.1.0] — 2026-09-26

### Added
- Рельса навигации с шестью разделами (Лента, Задачи, Проекты, Исполнители, Автопилот, Настройки), контекстная панель и командная строка с поиском и созданием задачи (T-004, T-005).
- Токены `--rail`, `--accent-beak`, `--status-*`; статус задачи показан полосой слева в строке списка и на карточке доски, агент-исполнитель помечен точкой (T-001, T-009, T-011).
- Кнопка «Передать агенту» в шапке карточки задачи (T-010).
- Первый экран лендинга: терминальная лента работы агента вместо скриншота (T-012).
- Шрифты Manrope, Unbounded, JetBrains Mono, отражены в `THIRD_PARTY_NOTICES.md` (T-003).

### Changed
- Палитра «Речная синь»: холодные нейтрали, синий основной цвет, один тёплый акцент для агентной активности, радиус 0.375rem (T-001, T-002).
- Русский словарь первичен: задача, лента, мои задачи, исполнители, отряды, среды, навыки, расход; локали en, zh-Hans, ja, ko переведены с русского, ключи не менялись (T-006, T-007).
- Список задач открывается по умолчанию вместо доски; фон колонок доски нейтральный (T-008, T-011).
- Онбординг описывает шесть разделов рельсы; документация и help CLI используют слово «задача» (T-015, T-016).
- Десктоп на macOS: рельса с отступом под кнопки окна (T-014).
- Лендинг: секции «Агент как исполнитель», «Свой контур», «Hermes внутри», «Установка за пять минут» со скриншотами нового интерфейса (T-013).
- Визуальные эталоны Playwright для трёх экранов в двух темах, команда `pnpm e2e:visual` (T-017).

### Removed
- Левый сайдбар `app-sidebar.tsx` и его тест; шрифты Montserrat и Comfortaa; скриншот `landing-hero.png`.
