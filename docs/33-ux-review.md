# Комплексное UX-ревью 1.2.0

Актуальность: 28 сентября 2026 года. Тикет T-031.

## 1. Как проводилось

Проверены все экраны продукта, а не три из T-023: 20 маршрутов приложения на локальном стенде (1440×900, светлая тема, aria-снимки), 4 публичные страницы с goosar.ru (светлая и тёмная), десктоп и потоки входа по коду и тестам. Четыре зоны, четыре независимых аудитора по одному брифу; эталон — ADR-0006 (10 эвристик NN/g, паттерны Carbon, HIG «Sidebars» и «Tab bars»). Находки из `docs/32-test-plan.md` §7 не повторяются. Тёмная тема экранов приложения и окно 1024px не проверены: съёмку остановили из-за нагрузки на машину, это отдельный пункт в T-032.

## 2. Итог

| Серьёзность | Сколько | Что значит |
|---|---|---|
| Critical | 4 | данные теряются или действие невозможно |
| High | 15 | мешает выполнить задачу |
| Medium | 29 | заметно, но обходится |
| Low | 27 | косметика и доступность |

Четыре Critical: удаление всех данных в деинсталляторе десктопа без подтверждения; в десктопе нет ⌘W для закрытия вкладки; тестовая страница «Оплата» доступна в проде и показывает сырые ошибки API латиницей.

Сквозные темы, которые повторяются во всех зонах:

- сырой `err.message` от API вместо понятного текста (создание задачи, автопилоты, биллинг, приглашения, вступление в воркспейс) — общий фикс через `describeServerFailure`;
- английские хардкоды в готовом интерфейсе (причины падения задач агента, подписи графика расхода, контекстное меню вкладок, деинсталлятор, страницы ошибок десктопа, `aria-label="агент"` без перевода);
- необратимые действия без подтверждения или отмены (деинсталляция, очистка лога демона, отклонение приглашения, массовое удаление автопилотов без отчёта о частичном сбое);
- безымянные кнопки и элементы вне таб-порядка (чат-виджет, архивирование в ленте, переключатель языка, недоступные форматы на /download);
- мёртвые якорные ссылки футера вне лендинга и отсутствие навигации в шапке сайта.
