# План реализации: поверхность Goosar 1.1

Актуальность: 25 сентября 2026 года.

## 1. Эпики

| Эпик | Цель | Зависит от | Оценка, дней |
|---|---|---|---|
| E1 Токены и шрифты | Новая палитра, радиусы, шрифты, статусные полосы во всём UI | — | 3 |
| E2 Каркас | Рельса, контекстная панель, командная строка | E1 | 4 |
| E3 Словарь | Русские термины, перевод en/zh-Hans/ja | — | 2 |
| E4 Экраны задач | Список по умолчанию, строка задачи, карточка с лентой агента | E1, E2 | 4 |
| E5 Лендинг | Первый экран с терминальной лентой, новые секции, скриншоты | E1, E4 | 2 |
| E6 Десктоп и релиз | Заголовок окна, трей, NOTICES, changelog, чек-лист | E2, E4 | 1.5 |

Итого 16.5 дней работы одного человека при полной занятости.

## 2. Порядок работ

```text
E1 Токены и шрифты
 → E2 Каркас          ── параллельно ── E3 Словарь
 → E4 Экраны задач
 → E5 Лендинг
 → E6 Десктоп и релиз
```

## 3. Критический путь

E1 → E2 → E4 → E5. Токены нужны каркасу (цвет рельсы), каркас нужен экранам (ширина рабочей области), экраны нужны лендингу (скриншоты). Словарь идёт параллельно с любого момента, но должен быть готов до скриншотов E5.

## 4. Вертикальные срезы

- E1 считается сделанным, когда `/{ws}/issues` в обеих темах открывается с новыми токенами и ни один элемент не остался оранжевым, кроме индикатора агента.
- E2 сделан, когда по рельсе можно пройти все шесть разделов мышью и клавиатурой, а панель сворачивается и запоминает состояние.
- E4 сделан, когда задачу можно создать, открыть, передать агенту и закрыть, не выходя из нового списка и карточки.
- E5 сделан, когда goosar.ru локально собирается со скриншотами нового интерфейса и без старого `landing-hero.png`.

## 5. Риски исполнения

- Захардкоженные цвета в `packages/views` (классы `bg-orange-*`, `text-amber-*`): grep перед E1, замена может занять день. План Б: временный alias токенов на старые классы через `@utility`.
- `app-sidebar.test.tsx` и тесты раскладки завязаны на текущую структуру DOM: переписываются вместе с E2, не после.
- Терминологические споры (ADR-0003): решить до E3, иначе локали правятся дважды.
- Desktop-сборка на macOS требует артефакт Hermes; для проверки E6 достаточно `electron-vite dev`, упаковка только для релиза.
